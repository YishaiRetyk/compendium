   - `#sec:<name>` → match the markdown heading whose text, after stripping leading `#` chars and surrounding whitespace, **slugifies to `<name>`**. Slugify = lowercase, trim, collapse internal whitespace runs to a single `-`, strip characters outside `[a-z0-9-]`. This is **case-insensitive** and space/punctuation-tolerant (so `#sec:self-attention` matches a `## Self-Attention` or `## Self Attention` heading). Slice from that heading line to the line before the next heading of the same-or-higher level (`#` count ≤ the matched heading's). No matching heading → None → `insufficient-locator`.
   - `#para<n>` → the n-th (1-indexed) blank-line-delimited paragraph of the **body only**: skip the YAML frontmatter block (the leading `---`…`---` fence) entirely; ATX headings (`#`-prefixed lines) are NOT paragraphs and are skipped; fenced code blocks (```` ``` ````) count as a single paragraph unit and internal blank lines inside a fence do NOT split it; list blocks (consecutive `-`/`*`/`N.` lines) count as one paragraph. `n` out of range → None → `insufficient-locator`.
   - `#t<start>-<end>` → for transcript sources, slice lines whose leading timestamp token falls within `[start,end]`. Define the recognized timestamp shape explicitly: a line beginning (after optional whitespace) with `HH:MM:SS` or `MM:SS` or a `[HH:MM:SS]`/`[MM:SS]` bracketed form. If NO line in the file carries a recognizable timestamp token, treat `#t` as unbounded → None → `insufficient-locator` (do NOT fall back to whole-document). This removes the prior "best-effort/vague" wording.
