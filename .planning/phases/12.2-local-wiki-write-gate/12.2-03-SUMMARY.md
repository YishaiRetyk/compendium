# Phase 12.2 Plan 03: Compose Write-Gate into Pre-Commit Hook Summary

Added the local wiki write-gate to `.githooks/pre-commit` by appending a 11-line block (5 substantive lines + 4 comment lines + 1 leading blank + closing `fi`) AFTER the existing 7-line sync-claude check. The hook now (1) syncs `CLAUDE.md` to match `AGENTS.md` if drift is detected (existing behavior, preserved verbatim), then (2) invokes `bash bin/lint.sh --strict --staged --category provenance` and prints a single actionable footer line on non-zero exit.

+# AND run the local wiki write-gate over staged changes (Phase 12.2).
 set -euo pipefail

 if ! bash bin/sync-claude.sh --check 2>/dev/null; then
     ...
     exit 1
 fi
+
+# Phase 12.2 / WGATE-01..04: local wiki write-gate over staged changes.

+    exit 1
+fi
