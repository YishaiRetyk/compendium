## Decisions Made

- **Single atomic commit:** Plan task definition expects per-task commits; Plan 05 has one logical task ("Author VERIFICATION.md, flip REQUIREMENTS.md, run sync gates"). Splitting into VERIFICATION.md commit + REQUIREMENTS.md commit would leave the intermediate state in a sync-gate-failing condition (drift between artifacts) — interdependent edits stay in one commit per the GSD task-commit protocol.
- **Phase-base SHA anchored to CONTEXT.md:** Phase 12.2 has no separate SPEC.md (the planning workflow used CONTEXT.md as the anchor for downstream plans). Anchoring `phase_base_sha` to the CONTEXT.md commit (`ded3f6e`) ensures `git diff ded3f6e..HEAD` captures every Phase 12.2 content commit (Plans 01-05) — sets a precedent for future SPEC-less phases. Plan 12.1 used SPEC.md commit; documented the divergence in VERIFICATION.md frontmatter `phase_base_anchor` field.
- **Status note harmonization across all 4 WGATE bullets:** Plan 04 had checkbox-flipped WGATE-01 and WGATE-04 during its documentation pass but did not add the standard NEUT-08-style `**Status:** Complete (Phase 12.2). See \`.planning/...\`.` annotation. Plan 05 added the annotation to all four bullets, ensuring consistent style across the WGATE family. The Phase 12.1 NEUT-08 bullet at `REQUIREMENTS.md:36` is the canonical precedent.
- **Scope-boundary on `--strict`:** the plan acceptance criterion for `bin/lint.sh --category yaml,provenance --strict` exit 0 was a precise contract for "no provenance regressions." When `--strict` triggers D-08 findings (DR-match for `[epistemic:: inferred]` claims) from the unrelated `a964beb` `ingest(hack-ai-coding-2026-05)` commit, those are NOT category `provenance` (they're category `strict`) and they're NOT regressions caused by Phase 12.2. Documented in VERIFICATION.md as a scope-boundary note + verified that the pure provenance check (`bin/lint.sh --category yaml,provenance`) exits 0 with zero findings on the live tree. This same pre-existing condition was documented in Plan 04 SUMMARY (`12.2-04-SUMMARY.md` "Issues Encountered").
