## Decisions Made

- **make_bare_repo over make_fixture_repo (D-19, planner discretion).** Phase-09's `make_fixture_repo` reads from `tests/phase-09/fixtures/<name>/` source directories; Phase 12.2's scenarios are simple enough to express each fixture inline via a `write_page` heredoc, so the fixture directory is unnecessary. The simpler helper makes each test fully self-contained.
- **Omit `seed_origin_main_ref` from lib.sh (D-19).** Staged-mode swaps the diff source from `origin/main...HEAD` to `git diff --cached --name-only --diff-filter=A`, so origin-ref seeding is unused. The function's name itself does not appear in `lib.sh` (a comment that originally referenced it was rewritten to satisfy the AC `! grep -q 'seed_origin_main_ref'`).
- **Hook-ordering test uses `git clone "$REPO_ROOT"` (PATTERNS.md §10).** Distinct from tests 1-8's `make_bare_repo` strategy because the hook chain (`.githooks/pre-commit` → `bin/sync-claude.sh` → `bin/lint.sh`) requires real script bodies present in the fixture, not just an empty git init. The `git -c core.hooksPath=.githooks commit ...` invocation activates the hook chain explicitly per-test (no global `core.hooksPath` mutation).
- **No-verify smoke test also clones (sanity-check only).** Mirrors the hook-ordering test's clone strategy because it likewise needs `.githooks/pre-commit` present to demonstrate that `git commit --no-verify` bypasses it. The test passes today -- it asserts git's own flag works, which it does.
- **`test_staged_requires_strict.sh` asserts exit 0 (the no-op contract).** Per D-05, `--staged` without `--strict` either no-ops (exit 0) or short-errors with a usage hint (exit 1). Both are acceptable. The recommended-default-no-op assertion is encoded; if Plan 02 lands the short-error behavior instead, the assertion will need a one-line flip (and the test acceptance criteria already permits either).
