**Root cause:** `PROV_RE` captures the support_type group using `[^|\]]+` — this matches characters until a pipe or closing bracket. In a markdown table cell, the pipe is escaped as `\|`, so the regex captures `direct\` (with trailing backslash) instead of `direct`. The fix is to strip the trailing backslash from the captured value before comparing.

**Normalization approach:** Add `.rstrip('\\')` at each point where `support_type` is extracted from a PROV_RE match group. This is minimal, targeted, and does not change PROV_RE itself (avoiding ripple effects on callers that use the raw captured value for other purposes).
