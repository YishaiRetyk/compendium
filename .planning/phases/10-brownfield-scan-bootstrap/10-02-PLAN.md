```python
    label: one of 'entity', 'concept', 'source', 'comparison', 'overview', 'unknown'
    confidence: one of 'high', 'medium', 'low', 'unknown'
```

Per D-16 — 4 signals (rule-based, NO LLM calls):
  1. Existing frontmatter `type:` — authoritative if present and valid per AGENTS.md §4
  2. Filename convention — PascalCase/proper-noun → entity; `YYYY-MM-DD-*` → journal/source; `src-*` → source summary; `vs-*` or `X-vs-Y` → comparison
  3. H1 + section-heading structure — `## Extracted Claims` + `## Source Metadata` → source summary; `## Comparison Table` → comparison; `## TL;DR` + `## Key Facts` + `## Detail` → entity/concept
  4. Inbound/outbound wikilink density — outbound-heavy + abstract framing → concept; inbound-heavy + proper-noun title → entity

**D-16 signal 4 Phase 10 scope (Codex review fix #3):** Phase 10 `scan` implements outbound link density only. Inbound link computation requires a full-vault two-pass walk (build target->source map across all pages, then look up inbound count per page). This is deferred to Phase 11 where `01-page-typing.sh` has full vault graph context and authoritative typing responsibility. The `classify_page()` API accepts an optional `inbound_count` parameter (default `None`) so Phase 11 can pass it without modifying the classifier module.

Per D-17 — mapping rule:
  `high` = 3+ signals agree OR explicit frontmatter `type:` valid
  `medium` = 2 signals agree
  `low` = 1 signal, ambiguous
  `unknown` = 0 signals match or signals conflict across candidate types

Per D-19 — built-in denylist:
  `.obsidian/**`, `.trash/**`, `templates/**`, `attachments/**`, daily-note patterns (`YYYY-MM-DD.md` at root or under `daily/`, `journal/`)

    ```python
    """Rule-based page classifier (BRWN-16, D-16).

    NO LLM CALLS. Called by bin/brownfield.sh scan AND Phase 11's
    01-page-typing.sh. Rule set is authored here once.
    """
    import re
    from pathlib import Path

    VALID_TYPES = {'entity', 'concept', 'source', 'comparison', 'overview', 'decision'}

    PASCAL_CASE_RE = re.compile(r'^[A-Z][a-zA-Z0-9]*(?:-[A-Z][a-zA-Z0-9]*)*$')
    DATE_PREFIX_RE = re.compile(r'^\d{4}-\d{2}-\d{2}[-_]')
    SOURCE_PREFIX_RE = re.compile(r'^src-')
    COMPARISON_PREFIX_RE = re.compile(r'^vs-|-vs-')

    H1_RE = re.compile(r'^#\s+(.+)$', re.MULTILINE)
    SECTION_RE = re.compile(r'^##\s+(.+)$', re.MULTILINE)
    WIKILINK_RE = re.compile(r'\[\[([^\]]+)\]\]')

    def classify_page(rel_path: str, frontmatter: dict | None, body: str) -> tuple[str, str, str]:
        # Signal 1: frontmatter type
        fm_type = None
        if frontmatter and isinstance(frontmatter.get('type'), str):
            t = frontmatter['type'].strip()
            if t in VALID_TYPES:
                fm_type = t

        # Signal 2: filename convention
        name = Path(rel_path).stem
        fn_guess = None
        if SOURCE_PREFIX_RE.match(name):
            fn_guess = 'source'
        elif COMPARISON_PREFIX_RE.search(name):
            fn_guess = 'comparison'
        elif DATE_PREFIX_RE.match(name):
            fn_guess = 'source'  # journal/source flavored
        elif PASCAL_CASE_RE.match(name):
            fn_guess = 'entity'

        # Signal 3: section-heading structure
        sections = set(SECTION_RE.findall(body or ''))
        sec_guess = None
        if 'Extracted Claims' in sections and 'Source Metadata' in sections:
            sec_guess = 'source'
        elif 'Comparison Table' in sections:
            sec_guess = 'comparison'
        elif 'TL;DR' in sections and 'Key Facts' in sections and 'Detail' in sections:
            sec_guess = 'entity'  # disambiguate via signal 4

        # Signal 4: wikilink density (outbound only; inbound requires whole-vault scan handled by caller)
        outbound_links = len(WIKILINK_RE.findall(body or ''))
        link_guess = None
        if outbound_links >= 5:
            link_guess = 'concept'  # outbound-heavy → concept

        # D-17 confidence mapping
        signals = {
            'frontmatter': fm_type,
            'filename':    fn_guess,
            'heading':     sec_guess,
            'links':       link_guess,
        }
        non_none = [v for v in signals.values() if v is not None]

        # Explicit frontmatter type is high-confidence per D-17
        if fm_type:
            label = fm_type
            confidence = 'high'
        else:
            # Count agreeing non-None signals by label
            from collections import Counter
            counter = Counter(non_none)
            if not counter:
                label, confidence = 'unknown', 'unknown'
            else:
                top_label, top_count = counter.most_common(1)[0]
                # Conflict detection: 2+ distinct labels with equal counts and total signals >=2
                distinct_labels = {v for v in non_none}
                if len(distinct_labels) >= 2 and top_count == 1:
                    label, confidence = 'unknown', 'unknown'
                elif top_count >= 3:
                    label, confidence = top_label, 'high'
                elif top_count == 2:
                    label, confidence = top_label, 'medium'
                else:
                    label, confidence = top_label, 'low'

        # Signal trace per D-17
        trace_parts = []
        trace_parts.append(f"frontmatter={fm_type or 'none'}")
        trace_parts.append(f"filename={fn_guess or 'none'}")
        trace_parts.append(f"h1={sec_guess + '-like' if sec_guess else 'none'}")
        if link_guess == 'concept':
            trace_parts.append("links=outbound-heavy")
        elif outbound_links == 0:
            trace_parts.append("links=none")
        else:
            trace_parts.append(f"links=outbound-{outbound_links}")
        signal_trace = ", ".join(trace_parts)

        return label, confidence, signal_trace


    def unknown_reason(rel_path: str, frontmatter: dict | None, body: str, signal_trace: str) -> str:
        """Return a concise one-line prose open-question per D-18.

        Format: `<path> — <signals-listed>. <Open question>?`
        Avoids pre-filled type suggestions; invites user judgment.
        """
        return f"`{rel_path}` — {signal_trace}. What kind of page should this become?"
    ```
