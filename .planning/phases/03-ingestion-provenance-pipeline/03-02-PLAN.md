#!/usr/bin/env bash

**Usage function:**
Print help when called with `--help`, `-h`, or no arguments:
```
Usage: bin/ingest.sh <source-file> [--slug <slug>]

Scaffolds source ingestion by:
  1. Creating dated directory structure in sources/
  2. Copying the source file into place
  3. Computing content_hash (SHA-256)
  4. Printing ready-to-ingest instructions for the LLM agent

Options:
  --slug <slug>   Custom slug for the source directory (default: derived from filename)
  --help, -h      Show this help message
```

**Argument parsing:**
- Required: `<source-file>` (positional, first non-flag argument)
- Optional: `--slug <slug>` (if omitted, derive slug from filename by lowercasing, replacing spaces/underscores with hyphens, removing non-alphanumeric-hyphen characters, and trimming the extension)
- Validate source file exists and is readable; exit 1 with error message if not

**Date computation:**
```bash
TODAY=$(date -u +%Y-%m-%d)
YEAR=$(date -u +%Y)
MONTH=$(date -u +%Y-%m)
```

**Directory creation:**
```bash
DEST_DIR="sources/${YEAR}/${MONTH}/${TODAY}-${SLUG}"
mkdir -p "${DEST_DIR}"
```

**File placement:**
- Get the source file's original extension
- Copy (not move) the file to `${DEST_DIR}/source${EXT}` where EXT is the original file extension (e.g., `.md`, `.pdf`, `.txt`)
- If file is `.md`, copy as `source.md` per AGENTS.md convention

**Hash computation (portable):**
```bash
compute_hash() {
    local file="$1"
    if command -v sha256sum &>/dev/null; then
        sha256sum "$file" | cut -d' ' -f1
    elif command -v shasum &>/dev/null; then
        shasum -a 256 "$file" | cut -d' ' -f1
    else
        echo "ERROR: No SHA-256 tool found. Install coreutils." >&2
        exit 1
    fi
}
HASH=$(compute_hash "$SOURCE_FILE")
```

=== Ready to Ingest ===

  Ingest the source at ${DEST_DIR}/source${EXT}

    content_hash: "sha256:${HASH}"
    ingested_at: ${TODAY}
    path: ${DEST_DIR}/source${EXT}

  Follow the Ingest Workflow in AGENTS.md section 11.1.
