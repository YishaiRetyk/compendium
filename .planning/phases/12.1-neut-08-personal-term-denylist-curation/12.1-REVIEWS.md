## Concerns

- **HIGH: Plan 01 negative-control uses `sed` with an unescaped anchor.**
  The plan correctly requires `grep -F` because terms may contain regex metacharacters, but then uses `sed "s|$ANCHOR|REDACTED|g"`, which is regex-based and can break or behave incorrectly for anchors containing `.`, `[`, `]`, `*`, `\`, `|`, or `&`. This undercuts the robustness rationale.

- **MEDIUM: Plan metadata omits output summary files from `files_modified`.**
  Plans 01-04 all require creating `12.1-XX-SUMMARY.md`, but those files are not consistently listed in `files_modified`. That can create drift for executors or plan-check tooling.

- **MEDIUM: Plan 03's autonomous/interactive boundary is correct but operationally fragile.**
  It depends on the user manually updating counts in `extrapolation-draft.md`. Later verification relies on those counts being accurate. The plan has safeguards, but this is still the most failure-prone part.

- **MEDIUM: Plan 04 computes `N` from full phase diff, but summary text may use Plan 03's N.**
  This is mostly addressed, but the REQUIREMENTS.md edit happens before the verification artifact. If the computed `N` differs from `12.1-03-SUMMARY.md`, the plan should explicitly require using computed diff-derived `N` everywhere.

- **LOW: Plan 01 RED state is locally intentional but still a footgun.**
  The plan says CI does not run `tests/phase-12.1/run.sh`, which is good. But any developer running all phase tests between Plan 01 and Plan 03 will see a failure. This is acceptable, but should be clearly marked in the summary and maybe in the test output.

- **LOW: Verification artifact may become overly large and brittle.**
  The artifact asks for many verbatim outputs and tables. That is defensible for closure evidence, but it increases chance of placeholder leftovers or stale pasted values.

## Suggestions

- Replace the Plan 01 `sed` negative-control with fixed-string replacement via Python, for example:
  ```bash
  python3 - "$ANCHOR" "$FIX/wiki/leak.md" <<'PY'
  import sys
  anchor, path = sys.argv[1], sys.argv[2]
  text = open(path, encoding="utf-8").read()
  open(path, "w", encoding="utf-8").write(text.replace(anchor, "REDACTED"))
  PY
  ```
  This matches the fixed-string intent and handles regex metacharacters safely.

- Add all required summary/evidence output files to each plan's `files_modified` list.

- In Plan 03, after user review, compute counts mechanically from the approved Kept section before append, rather than relying only on manual Summary updates.

- In Plan 04, require one final placeholder check:
  ```bash
  ! grep -R "<.*>" .planning/phases/12.1-neut-08-personal-term-denylist-curation/12.1-VERIFICATION.md
  ```
  Or use a narrower placeholder regex if angle brackets appear legitimately.

- In Plan 04, make the diff-derived `N` the single source of truth for REQUIREMENTS.md, VERIFICATION.md, and SUMMARY.md.
