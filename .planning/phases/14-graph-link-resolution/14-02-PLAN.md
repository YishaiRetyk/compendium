<objective>
Re-point bin/lint.sh's linkres category and --fix from the wrong-premise (self-alias invariant)
to the correct behavior: validate that every intra-wiki link target is a known page id, and rewrite
bare [[X]] to [[id|X]] for unique matches.

Purpose: The linkres category shipped by Phase 14-02 validates whether pages have self-aliases
(wrong premise). It must be re-pointed to validate resolvable link FORM: piped links with a known
id target are OK; bare links are errors; piped links with an unknown target are errors (unless
the target is a deliberate not-yet-existing id = knowledge gap, which stays in gap/info).
The --fix path flips from appending aliases to rewriting bare [[X]] → [[id|X]].

Output: bin/lint.sh with re-pointed linkres + --fix, LINT_VERSION 1.6.0. Re-pointed test suite
with 11 cases covering the new semantics: bare-link error, unknown-target error, unique-match
--fix, multi-match warning, knowledge-gap exclusion, idempotency, --strict compatibility.

Replace the entire `if should_run('linkres'):` block with new logic.

The new block structure:

```python
# ---------------------------------------------------------------------------
# Check 9.75: Link-target resolution (linkres) -- LINK-04, LINK-05, LINK-06
# Validates that every intra-wiki body link uses piped form [[id|Title]]
# with a known page id as the target.
# ---------------------------------------------------------------------------
if should_run('linkres'):
    print("  Checking intra-wiki link targets (linkres)...", file=sys.stderr)

    # Build id set: known page ids (exact, from frontmatter id field == filename stem).
    # This is the ONLY lookup needed for the gate: "is the target a known page id?"
    # Also rebuild obsidian_map if orphan block didn't run (for --fix norm_map matcher).
    known_ids = set()
    if 'obsidian_map' not in dir():
        obsidian_map = {}
        for fpath, fm, body, err in all_pages:
            if fm is None:
                continue
            pid = fm.get('id', '')
            if not pid:
                continue
            stem = os.path.splitext(os.path.basename(fpath))[0].lower()
            obsidian_map.setdefault(stem, set()).add(pid)
            for alias in (fm.get('aliases') or []):
                if alias:
                    obsidian_map.setdefault(str(alias).lower(), set()).add(pid)
        resolution_map = obsidian_map  # backward-compat alias for gap block

    for fpath, fm, body, err in all_pages:
        if fm is None:
            continue
        pid = fm.get('id', '')
        if pid:
            known_ids.add(pid.lower())
    # Also add filename stems as known (id == filename by convention, but belt-and-suspenders)
    for fpath, fm, body, err in all_pages:
        if fm is None:
            continue
        stem = os.path.splitext(os.path.basename(fpath))[0].lower()
        known_ids.add(stem)

    # Build norm_map for --fix unique-match lookup (reuse normalize_link helper).
    # norm_map: normalize(id OR title OR alias) -> set of page ids (for bare-link --fix matching)
    norm_map = {}
    for fpath, fm, body, err in all_pages:
        if fm is None:
            continue
        pid = fm.get('id', '')
        if not pid:
            continue
        stem = os.path.splitext(os.path.basename(fpath))[0]
        aliases = [str(a) for a in (fm.get('aliases') or []) if a]
        for name in ([stem, pid] + aliases):
            key = normalize_link(name)
            if key:
                norm_map.setdefault(key, set()).add(pid)
        if fm.get('title'):
            key = normalize_link(fm['title'])
            if key:
                norm_map.setdefault(key, set()).add(pid)

    # Build the scan worklist: all wiki pages + index.md + log.md
    linkres_scan = [(os.path.relpath(fpath), body)
                    for fpath, fm, body, err in all_pages
                    if fm is not None and body is not None]
    for special in ('index.md', 'log.md'):
        sp = os.path.join(wiki_dir, special)
        if os.path.isfile(sp):
            try:
                linkres_scan.append((os.path.relpath(sp), open(sp, encoding='utf-8').read()))
            except Exception:
                pass

    # Regex to distinguish piped from bare links
    _PIPED_RE = re.compile(r'\[\[([^\]|]+)\|([^\]]+)\]\]')
    _BARE_RE  = re.compile(r'\[\[([^\]|]+)\]\]')

    for rel, body in linkres_scan:
        # Find the source file path for --fix rewrites
        src_fpath = None
        if do_fix and not dry_run:
            for fpath, fm, b, err in all_pages:
                if os.path.relpath(fpath) == rel and b is not None:
                    src_fpath = fpath
                    break
            if src_fpath is None:
                # Could be index.md or log.md -- build abs path
                src_fpath = os.path.join(os.path.dirname(os.path.abspath(wiki_dir)), rel)

        # --- Check piped links: [[id|Display]] ---
        for target, display in _PIPED_RE.findall(body):
            target = target.strip()
            t_lower = target.lower()
            if t_lower in known_ids:
                continue  # OK: known page id
            # Not a known id -- check if it could be a gap (deliberate not-yet-existing id)
            # A gap target contains no spaces (it looks like a slug) OR is any value
            # that has no normalized match (truly unknown). Either way it is a gap, not linkres.
            # ONLY flag as linkres error if the target LOOKS like it should resolve but doesn't:
            # i.e., normalize_link(target) matches a known page (suggesting a malformed target).
            normed = normalize_link(target)
            matches = norm_map.get(normed, set()) if normed else set()
            if len(matches) == 0:
                # No normalized match either -> genuine gap (not-yet-existing page)
                # This is allowed per §3 (red links for knowledge gaps). Do not flag.
                continue
            elif len(matches) == 1:
                correct_id = list(matches)[0]
                add_finding('error', 'linkres', rel,
                            f"[[{target}|{display}]] piped link target '{target}' is not a "
                            f"known page id; did you mean '[[{correct_id}|{display}]]'?")
            else:
                add_finding('error', 'linkres', rel,
                            f"[[{target}|{display}]] piped link target '{target}' is not a "
                            f"known page id; normalized-matches multiple pages: {sorted(matches)}; "
                            f"manual disambiguation required")

        # --- Check bare links: [[X]] (no pipe) ---
        for bare_target in _BARE_RE.findall(body):
            bare_target = bare_target.strip()
            t_lower = bare_target.lower()
            normed = normalize_link(bare_target)
            matches = norm_map.get(normed, set()) if normed else set()

            if len(matches) == 0:
                # No match: genuine knowledge-gap red link. Stays in gap, not linkres.
                continue
            elif len(matches) == 1:
                # Unique match: this is a fixable bare link
                correct_id = list(matches)[0]
                add_finding('error', 'linkres', rel,
                            f"[[{bare_target}]] is a bare link (no pipe); use "
                            f"[[{correct_id}|{bare_target}]] instead (LINK-01: uniform piped form)")
                # --fix: rewrite bare [[X]] -> [[id|X]]
                if do_fix and not dry_run and src_fpath and os.path.isfile(src_fpath):
                    try:
                        content = open(src_fpath, encoding='utf-8').read()
                        # Rewrite ALL occurrences of exactly this bare link in the body.
                        # Regex: [[bare_target]] where bare_target has no pipe.
                        escaped = re.escape(bare_target)
                        rewrite_re = re.compile(r'\[\[' + escaped + r'\]\]')
                        new_content = rewrite_re.sub(
                            f'[[{correct_id}|{bare_target}]]', content)
                        if new_content != content:
                            with open(src_fpath, 'w', encoding='utf-8') as f:
                                f.write(new_content)
                            add_finding('info', 'autofix', rel,
                                        f'Rewrote bare [[{bare_target}]] -> '
                                        f'[[{correct_id}|{bare_target}]]')
                    except Exception as e:
                        print(f"  warn: --fix failed on {rel}: {e}", file=sys.stderr)
            else:
                # Multi-match: warn, no rewrite
                add_finding('warning', 'linkres', rel,
                            f"[[{bare_target}]] bare link normalized-matches multiple pages: "
                            f"{sorted(matches)}; manual disambiguation required "
                            f"(cannot auto-fix -- ambiguous target)")
```
