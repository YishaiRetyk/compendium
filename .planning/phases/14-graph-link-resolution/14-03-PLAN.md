**Step B — Verify examples/ is clean via a DEDICATED scanner (review MEDIUM — NOT bin/lint.sh):**
examples/ pages carry `example: true` and live under EXCLUDE_DIRS, so `bin/lint.sh --category
linkres examples/` reports 0 errors UNCONDITIONALLY (it skips them). A clean exit there is VACUOUS
and proves nothing. Verify examples/ with a standalone scanner that (a) masks YAML frontmatter,
fenced code blocks, inline code spans, and HTML comments (same span types as 14-02's mask_markdown,

(any `[[X]]` with no pipe). A compact reference scanner:
```bash
python3 - <<'PY'
import re, pathlib, sys
FM   = re.compile(r'\A---\n.*?\n---\n', re.DOTALL)
FENCE= re.compile(r'(^|\n)(```|~~~)[^\n]*\n.*?\n\2[ \t]*(?=\n|$)', re.DOTALL)
COM  = re.compile(r'<!--.*?-->', re.DOTALL)
INL  = re.compile(r'`[^`\n]*`')
BARE = re.compile(r'\[\[([^\]|\n]+)\]\]')   # bare: no pipe
def mask(t):
    for rx in (FM, FENCE, COM, INL):
        t = rx.sub(lambda m: ''.join('\n' if c=='\n' else ' ' for c in m.group(0)), t)
    return t
bad = []
for p in pathlib.Path('examples').rglob('*.md'):
    masked = mask(p.read_text(encoding='utf-8'))
    for m in BARE.finditer(masked):
        bad.append(f"{p}: [[{m.group(1).strip()}]]")
if bad:
    print("BARE LINKS REMAIN in examples/:"); print("\n".join(bad)); sys.exit(1)
print("PASS: examples/ has zero bare intra-cluster links (masked scan)")
PY
```
This is the real functional check: every intra-cluster reference is piped `[[id|Title]]`, so it
resolves by filename within the examples/kahneman/ vault subtree. (The scanner does NOT flag piped
