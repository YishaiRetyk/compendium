  <action>
Run the full lint workflow and validate results:

1. **Full lint run:** Run `bash bin/lint.sh wiki/` (without --dry-run, without --fix) to generate the full report. Capture stdout+stderr.

2. **Stdout validation:** Verify output contains:
   - Error/Warning/Info counts
   - Top findings listed
   - Path to lint-report.md

3. **Report validation:** Read `wiki/maintenance/lint-report.md` and verify:
   - Valid YAML frontmatter with id: lint-report, type: overview, has_contradictions: false, knowledge_domain: ""
   - Sections for Errors, Warnings, Info with counts in headings
   - Findings listed under each section

4. **Log validation:** Read `wiki/log.md` and verify a lint log entry was appended with:
   - Header format: `## [YYYY-MM-DD] lint | wiki health check`
   - Total findings count with per-severity breakdown
   - auto_fixes: 0 (since --fix was not used)

5. **Dry-run validation:** Run `bash bin/lint.sh wiki/ --dry-run`. Verify it does NOT modify lint-report.md `updated_at` or append to log.md. Compare file modification timestamps before and after.

6. **Category-specific run:** Run `bash bin/lint.sh wiki/ --dry-run --category orphan` and verify it runs only orphan checks (output should only contain orphan-related findings).

7. **Idempotency check (addresses Codex review concern):** Run `bash bin/lint.sh wiki/` a second time. Compare the two lint-report.md outputs -- they should have identical structure and findings. Only `updated_at` and log entry count should differ. Specifically:
   - Same number of findings per category
   - Same finding messages
   - `created_at` preserved from first run

8. **Category coverage audit:** For each of the 7 detection categories, document whether it produced findings and why:
   - **yaml**: Expected findings if any pages missing new fields or have validation issues
   - **provenance**: Expected findings if any broken prov refs exist
   - **orphan**: Expected findings on small wiki (some pages may lack inbound links)
   - **crossref**: Expected findings if related pages lack mutual links
   - **stale**: May have zero findings if all content was recently ingested (this is correct behavior, not a bug)
   - **contradiction**: May have zero findings if no entity/concept pages have multi-source sections (correct behavior -- overview/comparison excluded)
   - **gap**: Expected maturity guardrail skip message (wiki likely has < 5 domains)
   
   For each category that produces zero findings, document the reason. The validation criterion is "each category executes correctly" not "each category produces findings."

9. **Fix any issues:** If any crashes, malformed output, or missing categories are found, fix them in bin/lint.sh before proceeding to human review.
