    ```bash
    #!/usr/bin/env bash
    # bin/requirements-sync.sh -- DEBT-03: mechanical traceability check
    # Compares REQUIREMENTS.md status checkboxes against per-phase VERIFICATION.md truths.
    # Advisory default (exit 0); --strict exits 2 on drift.
    set -euo pipefail
    ```

    Flag parsing: `--help|-h`, `--format <text|json>`, `--strict`, `--phase N`, `--root DIR`.

    Default `ROOT=".planning"`; REQUIREMENTS at `$ROOT/REQUIREMENTS.md`; VERIFICATION files discovered via:
    ```bash
    find "$ROOT" -maxdepth 3 -name '*VERIFICATION.md' -type f
    ```
    (Also handles fixture layout with VERIFICATION files directly under ROOT by virtue of maxdepth 3.)

    Core work in a single python3 heredoc that:
      1. Parses REQUIREMENTS.md traceability table rows: regex `^\|\s*([A-Z]+-\d+)\s*\|\s*Phase\s*(\d+)\s*\|\s*(\w+)\s*\|`.
      2. For each VERIFICATION.md file, parses bulleted lines matching `-\s*([A-Z]+-\d+)\s*:\s*(\w+)` into a dict.
      3. For each REQ-ID (optionally phase-filtered), compares statuses and builds row with columns: req_id, req_md_status, verif_md_status_or_"(not found)", drift_flag, note. **Records the phase number from the REQUIREMENTS.md traceability row** (used for the `phase` field in JSON output).
      4. Drift is True iff both sides present and statuses normalize to different values (case-insensitive; format variants per behavior section are normalized first — checkbox and emoji prefixes stripped before parsing).
      5. **For duplicate REQ-IDs across VERIFICATION files: process files in lexicographic path order, last-write-wins on status; emit `WARN:` to stderr per duplicate.**
      6. Emits markdown table (with Advisory-mode note prefix) OR JSON array based on `$FORMAT`. JSON entries always include `phase` (integer or null).
      6. Prints summary line with count of drift rows to stderr.

    After python emits output, bash reads an exit hint: in `--strict` mode, if python exported `DRIFT_COUNT > 0` (via a sentinel line or file), bash exits 2; otherwise 0.

    Wire a `--help` that documents every flag with exit-code matrix per convention.
