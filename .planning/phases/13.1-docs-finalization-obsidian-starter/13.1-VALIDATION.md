# Phase 13.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> This is a docs + manual-verification + starter phase — "tests" are deterministic bash/grep gates over markdown artifacts, not xUnit tests.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Repo bash gates (`bin/lint.sh`, `bin/check-neutrality.sh`, `bin/validate-op.sh`, `bin/sync-claude.sh`) + `git diff`/`grep` structural checks. No xUnit framework. |
| **Config file** | none — gates are scripts in `bin/` |
| **Quick run command** | `bash bin/lint.sh --category yaml,provenance,orphan,crossref && bash bin/check-neutrality.sh` |
| **Full suite command** | `bash bin/lint.sh && bash bin/check-neutrality.sh` |
| **Estimated runtime** | ~30 seconds |

---

## Sampling Rate

- **After every task commit:** Run `bash bin/lint.sh --category yaml,provenance,orphan,crossref && bash bin/check-neutrality.sh`
- **After every plan wave:** Run `bash bin/lint.sh && bash bin/check-neutrality.sh` + drift-guard + index-coverage check
- **Before `/gsd-verify-work`:** All gates green; `13.1-VERIFICATION.md` populated for DEBT-02/04 (DEBT-01 slot marked "awaiting user render")
- **Max feedback latency:** ~30 seconds
