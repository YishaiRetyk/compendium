## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-08 | Tampering | ingest.sh --asset path traversal via basename | mitigate | The destination filename is derived via `basename "${ASSET_FILE}"`, which strips any directory component, so an asset path cannot write outside the dated bundle dir. All paths are quoted. File-existence check before cp. |
| T-20-09 | Tampering | lint.sh original_asset suffix match on untrusted YAML | mitigate | The check is read-only: `isinstance(oa, str)` guards non-string YAML; `.lower().endswith('.pdf')` is a pure string op with no shell/eval. A malicious original_asset value can at worst cause a benign missing-field finding. |
| T-20-10 | Tampering | test fixtures mutating the real sources/ or wiki-cloud/ tree | mitigate | All test fixtures use mktemp dirs + EXIT-trap cleanup; the --asset integration test runs ingest in an isolated temp cwd so the real tree is never written. Acceptance asserts `git status --porcelain sources/ wiki-cloud/` is empty post-run. |
