# v1.5 Python Migration — Milestone Audit

**Shipped:** 2026-07-03 · **Phases:** 24–26 (17 plans) · **Requirements:** 18/18 Complete
(`requirements-sync --strict --require-complete` exits 0)

## What shipped

A pure internal re-platforming of the `bin/` toolchain from Bash to Python, behind `.sh`
exec-shims, with **byte-behavior parity as the acceptance bar throughout**. The system's
observable behavior is unchanged; its implementation is now Python. Three phases:

1. **Phase 24 — Foundation.** Installable `src/`-layout package (pinned deps, 6 required CI
   checks); a frozen `compendium.common` shared core; and the `WIKI_IMPL=bash|py` **parity
   oracle** — a git-worktree-backed frozen-bash reference with 4-channel byte capture. Built
   first because it was the one hard serialization point: everything downstream diffs against it.
2. **Phase 25 — Parallel Migration + Cutover.** All 16 tools ported cluster-by-cluster behind
   the frozen surface, each flip gated against the held-fixed bash oracle (238 paired routed
   calls byte-identical), then fanned in through a single cutover. `migrate-privacy-dirs`
   retired; the migration decision record authored.
3. **Phase 26 — Wholesale CLI→Pytest Conversion.** The black-box bash suites became a pytest
   collector running each `phase-*/test_*.sh` against the real Python `bin/` — a **bridge, not
   a rewrite** (D-26-01). With one implementation left, the entire parity apparatus was retired
   (22 files), which unblocked the read-only `lint --staged`/`--ci` fix that ended the
   per-commit pre-commit wiki-clobber.

## What the reviews caught (the milestone's real value)

Every phase closed with an xhigh adversarial review; the catches were substantive, not cosmetic:

- **Phase 24 (22 findings):** the routing gate was red at HEAD; the local git hooks had been
  silently disabled since April; a subshell capture-key collision had gutted per-call parity
  coverage (the oracle looked green while measuring almost nothing). All fixed + re-verified.
- **Phase 25 (15 findings):** a greenfield `ruamel` import block that failed every commit
  (fixed via a lazy `common` re-export); parity harness gaps surfaced at the first LIVE
  cross-run channel comparison (Phase 24's empty-manifest short-circuit had never exercised it).
  5 D-09 rebases over the phase, each re-pinned.
- **Phase 26:** see `phases/26-cli-pytest-conversion/26-REVIEW.md`.

The throughline: the parity apparatus was worth building even though it was thrown away — it
turned "the port looks right" into "the port is byte-identical," and the reviews repeatedly
found places where a green signal was actually measuring nothing.
