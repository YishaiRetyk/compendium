# Attention Mechanism

## TL;DR

- Attention lets models weight input tokens dynamically. [epistemic:: inferred]
- Transformers rely on attention instead of recurrence. [epistemic:: inferred]

## Key Facts

- Scaled dot-product attention is the canonical form. [epistemic:: inferred]
- Multi-head attention runs several attention projections in parallel. [epistemic:: inferred]

## Detail

Attention mechanisms compute weighted sums of value vectors based on
query-key similarity.  See [[Transformer]] and [[Deep Learning]].
