# Deep Learning

## TL;DR

- Deep learning stacks differentiable layers to learn representations.
- [[Attention Mechanism]] and [[Transformer]] are central modern examples.
- [[Geoffrey Hinton]] is a widely-cited pioneer.

## Key Facts

- Backpropagation is the core training algorithm.
- Large-scale GPUs drove the 2010s breakthroughs.

## Detail

Deep learning unified several earlier neural network strands into a
single practical paradigm.
