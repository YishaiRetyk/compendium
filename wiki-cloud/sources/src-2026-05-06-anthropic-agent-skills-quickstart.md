## TL;DR

Anthropic's API quickstart for Agent Skills: list available pre-built Skills via `GET /v1/skills?source=anthropic`, then invoke one by passing `container.skills: [{type: "anthropic", skill_id: "<id>", version: "latest"}]` to the Messages API alongside the `code_execution_20250825` tool and the `code-execution-2025-08-25` and `skills-2025-10-02` beta headers. The model creates output files inside the code-execution container; their `file_id`s are returned in tool-result blocks and are downloaded via the Files API at `GET /v1/files/{file_id}/content` with the `files-api-2025-04-14` beta. The tutorial walks the loop with `pptx` (presentation), `xlsx` (spreadsheet), `docx` (document), and `pdf` (PDF) Skills.

## Key Takeaways

- Pre-built Anthropic-managed Skills are listed via `GET /v1/skills?source=anthropic` with the `skills-2025-10-02` beta header [prov:src-2026-05-06-anthropic-agent-skills-quickstart#sec:step-1-list-available-skills|direct|2026-05-06] [epistemic:: sourced]
- The four pre-built `skill_id`s returned at the time of doc capture are `pptx`, `xlsx`, `docx`, and `pdf` [prov:src-2026-05-06-anthropic-agent-skills-quickstart#sec:step-1-list-available-skills|direct|2026-05-06] [epistemic:: sourced]
- Listing the API exposes only Skill metadata (name + description) — implementing the first level of progressive disclosure where Claude discovers Skills without loading their full instructions [prov:src-2026-05-06-anthropic-agent-skills-quickstart#sec:step-1-list-available-skills|direct|2026-05-06] [epistemic:: sourced]
- The Messages API request shape requires `container.skills` (a list of `{type, skill_id, version}` objects) AND `tools: [{type: "code_execution_20250825", name: "code_execution"}]` together — code execution is required for Skills [prov:src-2026-05-06-anthropic-agent-skills-quickstart#sec:step-2-create-a-presentation|direct|2026-05-06] [epistemic:: sourced]
- The required beta headers for an API Skills call are `code-execution-2025-08-25` and `skills-2025-10-02`; downloading generated files additionally requires `files-api-2025-04-14` [prov:src-2026-05-06-anthropic-agent-skills-quickstart#sec:step-2-create-a-presentation|direct|2026-05-06] [epistemic:: sourced]
- Files generated by a Skill live inside the code-execution container; their `file_id` is returned in `code_execution` tool-use result blocks and downloaded via `GET /v1/files/{file_id}/content` [prov:src-2026-05-06-anthropic-agent-skills-quickstart#sec:step-3-download-the-created-file|direct|2026-05-06] [epistemic:: sourced]
- Skill version is specified as `version: "latest"` in the container parameter — pinning the most recently published version of the Skill [prov:src-2026-05-06-anthropic-agent-skills-quickstart#sec:step-2-create-a-presentation|direct|2026-05-06] [epistemic:: sourced]
- Type discrimination on `skills[].type` is `"anthropic"` for Anthropic-managed pre-built Skills, distinguishing them from custom-uploaded Skills [prov:src-2026-05-06-anthropic-agent-skills-quickstart#sec:step-2-create-a-presentation|direct|2026-05-06] [epistemic:: sourced]
- The model identifier used in all quickstart examples is `claude-opus-4-7` [prov:src-2026-05-06-anthropic-agent-skills-quickstart#sec:step-2-create-a-presentation|direct|2026-05-06] [epistemic:: sourced]

## Notes

This source operationalizes the abstract architecture defined in [[src-2026-05-06-anthropic-agent-skills-overview|Anthropic Agent Skills Overview]] — translating "three-level progressive disclosure" into a concrete request body, beta headers, and a file-download loop. Compiled into [[agent-skills|Agent Skills]] and [[claude-api|Claude API]].

The quickstart is notable for what it does NOT cover: it walks the *consumer* path (use a pre-built Skill), not the *author* path (write a SKILL.md). Authoring guidance lives in [[src-2026-05-06-anthropic-agent-skills-best-practices|Anthropic Agent Skills Best Practices]].

The four code-block columns (cURL / `ant` CLI / Python / TypeScript) in the doc are not separate claims — they are the same operation expressed in four interfaces. Provenance for any one of them is sufficient for downstream extraction.
