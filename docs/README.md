# docs/

This directory follows the [Diátaxis](https://diataxis.fr) framework.

| Track | Type | File |
|-------|------|------|
| Tutorial (learning-oriented) | Tutorial | [quickstart.md](quickstart.md) |
| How-to: guided (wizard track) | How-to | [guided-setup.md](guided-setup.md) |
| How-to: manual (hand-edit track) | How-to | [manual-setup.md](manual-setup.md) |
| Reference + explanation | Reference | [reference/index.md](reference/index.md) |

The quickstart is for first-time users ("get something working"). guided-setup and manual-setup are complementary paths to the same end state; pick one. The reference directory contains deep explanation of schema, CI, privacy, brownfield, examples, and release workflow.
